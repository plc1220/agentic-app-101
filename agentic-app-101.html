CContainers and project structure

Synchronous requests
and background jobs

SHORT TASK

Wait for the result

Question → API → answer. Stream text or progress while waiting.

Good for a small lookup.
LONG TASK

Track a job

Submit → job ID → worker → saved result. The screen checks progress.

Good for processing a large document set.
Key pointA queue organizes work. A cache speeds up access. Their jobs differ.
