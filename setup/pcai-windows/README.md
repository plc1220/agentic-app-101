# PCAI DeepSeek setup for Windows

Download the [ready-to-share installer ZIP](../../downloads/PCAI_DeepSeek_Windows_AutoSetup.zip?raw=1).

Attendees extract it, double-click **Setup PCAI.cmd**, and paste their own PCAI API token. Setup creates an **OpenCode PCAI** desktop shortcut. There are no configuration files or placeholders to edit.

## Attendee steps

1. Install the OpenCode Desktop v1 build supplied by IT and connect to the PCAI VPN.
2. Extract the ZIP and open **Setup PCAI.cmd**.
3. If prompted, select the installed OpenCode Desktop application.
4. Paste the API token at the hidden prompt and press Enter.
5. After **SETUP COMPLETE**, save your work and fully quit OpenCode, including the tray instance.
6. Open the **OpenCode PCAI** desktop shortcut and send `Hello`.

The shortcut supplies the PCAI certificate and prefilled configuration. Setup copies these into the attendee's own Windows profile, so the extracted sharing folder can be removed afterward. Rerun setup to update the token, or press Enter to keep the existing one.

This configures **OpenCode as a coding assistant**. The workshop demo application still uses its own Gemini configuration.

## How setup works

- Uses native Windows PowerShell commands. No Python, Node.js, administrator elevation, or downloaded dependencies are required on attendee computers.
- Finds OpenCode in common install locations, with a file picker for custom locations.
- Writes only its own files under `%USERPROFILE%\.config\opencode\pcai`, restricted to the current Windows account.
- Saves the token locally as `api-token`. The token is entered through `Read-Host -AsSecureString`, never inserted into a command argument or written into the sharing package.
- Loads its dedicated `pcai.json` through `OPENCODE_CONFIG`. OpenCode merges this with existing settings. Existing global JSON and JSONC files are not edited.
- Sets DeepSeek as the default model in that configuration.
- Creates **OpenCode PCAI.lnk** on the user's actual Desktop, including redirected Desktops.
- Sets `NODE_EXTRA_CA_CERTS` and `NODE_TLS_REJECT_UNAUTHORIZED=1` only in the launched application's environment. It does not import a machine-wide CA or change PowerShell execution policies.
- Stops before starting another OpenCode process with stale certificate settings. It does not kill running work.
- Checks the bundled CA file hash. The certificate is public, but the endpoint still requires VPN access and an authorized API token.

OpenCode v2 uses a different provider schema. Setup detects a reported major version of 2 or higher and asks for an IT-provided matching package rather than writing v1 settings.

## Maintain the package

`Setup-PCAI.ps1` is the readable setup source. `Setup PCAI.cmd` contains the same code as an ordinary inline PowerShell command, generated by the builder. It does not load a script file, encode a payload, or disable execution policies. Organization application controls can still block it; ask IT to approve the package in that case.

After editing the setup source or packaged files, rebuild with Python 3:

```bash
python tools/build_pcai_windows.py
python -m unittest discover -s tests -p test_pcai_windows_package.py
```

The builder checks the CA hash and local token-file reference, uses an explicit file allowlist, and rejects private keys, JWT-shaped credentials, and manual replacement placeholders. It produces a reproducible ZIP and excludes the setup source, tests, and every local token file.

## Validation scope

On macOS on 23 November 2026, Microsoft PowerShell parsed the readable and generated setup code. The actual file-update function passed first-write, unchanged-rerun, and update checks. OpenCode 1.3.15 loaded the generated configuration, resolved its relative token-file reference, selected DeepSeek by default, and preserved another provider and an existing JSONC file unchanged.

Windows ACLs, executable discovery, hidden token entry, desktop shortcut creation, and a live Windows DeepSeek reply still require a first Windows acceptance run. Setup does not claim success for a live model connection; attendees verify that after opening the shortcut.
