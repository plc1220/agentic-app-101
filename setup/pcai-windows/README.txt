PCAI DEEPSEEK FOR OPENCODE ON WINDOWS

Before you start
- Use the OpenCode Desktop version supplied by IT. This package supports v1.
- Connect to your PCAI VPN.
- Have your own PCAI API token ready.

Setup
1. Extract the whole ZIP into a folder.
2. Double-click Setup PCAI.cmd.
3. If asked, select your installed OpenCode Desktop application.
4. Paste your API token when asked and press Enter. It stays hidden.
5. Wait for SETUP COMPLETE.
6. Save your work and fully quit OpenCode, including its system tray instance.
7. Double-click OpenCode PCAI on your Desktop. Send Hello to check the connection.

No file editing, address replacement, Python installation, or administrator login
is required. Use the new desktop shortcut each time, including after a restart.
You can delete the extracted setup folder after setup completes.

To replace your token, run Setup PCAI.cmd again. Press Enter to keep an existing
token. Setup leaves your existing OpenCode configuration files unchanged.

Your token is stored under your Windows account, outside this sharing folder.
Share only the original ZIP. It contains no API token or private key.

If Windows or your organization blocks setup, ask IT to approve this package.
Keep Windows protections enabled. If a token is rejected, ask your PCAI
administrator to check its expiry and endpoint access. For timeouts, check VPN.

This configures the OpenCode coding assistant. It does not change the separate
workshop demo application's Gemini settings.
